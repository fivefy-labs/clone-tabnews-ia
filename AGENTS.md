# AGENTS.md

Contexto e diretrizes do projeto para agentes de IA.

## Visão Geral do Projeto

- **Objetivo**: Implementação do TabNews (https://tabnews.com.br) para o https://curso.dev utilizando agentes de IA.

## Stack e Tecnologias

- **Framework**: Next.js (App Router)
- **Biblioteca Base**: React
- **Linguagem**: JavaScript
- **Gerenciador de Pacotes**: npm

## Comandos Principais

- `npm run dev`: Inicia o servidor local de desenvolvimento.
- `npm run build`: Executa o build de produção do Next.js.
- `npm run start`: Inicia o servidor em modo de produção.
